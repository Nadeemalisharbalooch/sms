Timetable Generator System

School Management System (SMS) Architecture & Summary

Architecture Proposal

1. Executive Overview

The Timetable Generator Module automates the creation of clash-free weekly class schedules. It integrates existing school data (Classes, Sections, Subjects, and Teacher Allocations) with a new Time Slots (Periods) engine.

2. Data Requirements Breakdown

✅ Already in Existing Project

  • Academic Sessions
  • Classes & Sections
  • Subjects & Class Subjects
  • Subject Allocations (Teacher ↔ Subject ↔ Class)

🆕 New Data to be Added

  • Time Slots Table (Periods 1 to 6, Recess/Break)
  • Timetable Entries Table (The generated schedule)
  • Weekly Period Limits (e.g. Math = 6/week)

4. Clash Detection Rules (Constraint Engine)

🔒 Hard Constraints (Must NEVER be violated):
  • Teacher Clash Protection: A teacher cannot teach two classes at the same time slot on the same day.
  • Class Clash Protection: A class cannot have two lectures at the same time.
  • Break Slot Protection: Slots marked as break (Recess/Lunch) cannot have lectures.
  • Subject Allocation Binding: Only assigned teachers can take their respective subjects.
✨ Soft Constraints (Quality Optimization):
  • Even Distribution: Spread subjects evenly across working days (e.g. 1 Math period per day).
  • Teacher Workload Balance: Avoid scheduling more than 3-4 consecutive periods for any teacher without a break.

5. API Endpoints Architecture

Method Endpoint Description
GET / POST /api/institutes/timetable/slots Manage daily periods and timings
POST /api/institutes/timetable/generate Run automated clash-free timetable generator
GET /api/institutes/timetable/class Fetch timetable by Class & Section
GET /api/institutes/timetable/teacher Fetch personal timetable for a specific Teacher
GET /api/institutes/timetable/master View full school Master Grid timetable
POST /api/institutes/timetable/entries/swap Manually drag/swap periods with live clash validation

6. How Generation Works (Summary)

  1. Admin configures the school's Time Slots (Periods 1-6 + Break).
  2. Admin calls the Generate API with active session and working days (Monday-Saturday).
  3. The system picks Subject Allocations, creates an empty weekly grid, and assigns periods using a Backtracking Clash-Free Algorithm.
  4. The finalized schedule is saved into timetable_entries and is ready to view and export.
